INVITACIÓN AZAIRUS 2026 — GITHUB PAGES

1. Abre tu repositorio de GitHub en la rama main.
2. En Add file > Upload files, sube el archivo index.html Y la carpeta assets completa (conservando sus nombres).
   Si GitHub no acepta arrastrar la carpeta, arrastra juntos index.html y la carpeta assets desde el explorador.
3. Pulsa Commit changes.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Abre tu enlace https://USUARIO.github.io/REPOSITORIO/ y recarga después de unos minutos.

NO SUBAS EL ZIP SIN DESCOMPRIMIR. GitHub Pages necesita index.html y assets/ en la raíz.

La música es un instrumental ORIGINAL generado en el navegador, no la canción de Lorde. Requiere tocar el botón ♫.
